## The Menstrual Cycle: A Simulation

The Menstrual Cycle: A Simulation is a independent, student-led project which explores and breaks down the physiological processes and biological interactions driving the menstrual cycle. The model focuses on understanding of the cycle's cause and mechanisms, rather than fixed-day memorization. Information is illustrated through visual animation including anatomy, hormones, and biological components; textual support; and the flexibility of repetition at a controlled pace. Created to support women of all ages and expand knowledge concerning an underrepresented topic, the model is not a substitute for medical advice. 

Live Demo: https://menstrual-cycle-simulation.vercel.app/

Key Features:
- Morphing anatomy
- Draggable timeline or guided learning "What Happens Next" button
- Visual depiction of hormonal signaling and subsequent influence
- Multiple conditions including PCOS, POI, FHA

Technology Used:
Next.js, TypeScript, Framer Motion, Figma/SVG, Vercel, Canva

AI such as Claude Code, Claude Design, and ChatGPT was utilized and essential to the development of this website. 

Running Locally:
1. npm install
2. npm run dev

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
